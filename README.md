# People Manager

## Visão geral

Este repositório foi estruturado como um monorepo para suportar um backend .NET 8 e um frontend React/TypeScript.

## Estrutura inicial

- backend/: solução .NET com as camadas Domain, Application, Infrastructure e Api
- frontend/: será criado nas próximas fases
- docs/: decisões de arquitetura registradas em formato ADR-lite

## Fase 1 concluída

A primeira fase foi iniciada com:

- estrutura de monorepo
- solução .NET 8 com projetos base
- modelo inicial de Employee, EmployeePhone e Role
- documentação inicial de decisões
